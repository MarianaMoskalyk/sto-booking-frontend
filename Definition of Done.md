Definition of Done (Документаційний критерій):
✅ Код та структура: Код відповідає стандартам проєкту, не містить закоментованих ділянок та логів відладки (console.log).
✅ Перевірка (Review): Пройдено Pull Request review хоча б одним іншим учасником команди.
✅ Документування коду: Для складних функцій та компонентів додано коментарі (JSDoc).
✅ Оновлення README: Якщо таска додає нову сторінку або змінює логіку запуску, інструкція в README.md актуалізована.
✅ Запис у CHANGELOG: Усі реалізовані фічі внесені до секції [Unreleased] файлу CHANGELOG.md.
✅ Архітектурна відповідність: Якщо рішення відрізняється від початкового плану, створено або оновлено відповідний ADR.
✅ Метадані: В описі таски в Jira додано посилання на відповідний коміт у GitHub.
